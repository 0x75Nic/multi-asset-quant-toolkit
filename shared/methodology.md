# 统一方法学：突破追单扫描

三个资产模块（加密 / A股 / 美股）共用同一套技术分析框架。本文件是**唯一事实来源**，
改算法只改这里，三模块同步。

## 核心算法（伪代码）

```
输入: 日K (open/high/low/close), 当前价 last
1. 均线      SMA20 = mean(close[:20]); SMA50 = mean(close[:50])
2. RSI14     Wilder 平滑: 涨/跌均值 → RSI = 100 - 100/(1+ag/al)
             >=70 超买 / <=30 超卖 / 其余中性
3. ATR14     14 期 True Range 均值; atrp = atr/last
4. 摆动高低  局部极值 (左右各2根更高/更低) → 阻力/支撑
5. 突破触发  trig = max(high[:10]) * 1.004        # 近10日高 +0.4%
6. 止损      stop = trig - 1 * ATR
7. 目标      TP1 = trig + 2R ; TP2 = trig + 3R     # R = trig - stop
8. 杠杆      按 atrp 分档 (见下)
9. 仓位      名义 = 账户 × 风险预算% ÷ (R/trig)
             风险预算: atrp<6%→2%, 否则1.5% (A股同理, 略调)
```

## 杠杆分档（按 ATR%）

| atrp | 加密 | A股 | 标签 |
|---|---|---|---|
| <3% | 5x | 3x | 低波动 |
| 3–5% | 3x | 2x | 中波动 |
| 5–8% | 2x | 1.5x | 高波动 |
| 8–12% | 1.5x | 1x | 极高波动 |
| >12% | 1x | 1x | 极端 |

> 加密波动天然大于 A股，故同 atrp 下加密杠杆更高；但绝对上限都受压（加密≤5x、A股≤3x）。

## 资产专属层

| 模块 | 专属处理 |
|---|---|
| 加密 | HyperLiquid 链上验证(费率/OI/成交额) + OKX 条件单生成 + tradingbeats 假数据过滤 |
| A股 | T+1 提醒 / 涨跌停判定(主板±10%, 创业/科创±20%) / 北向资金 / 多源K线(东财+新浪) |
| 美股 | TradingAgents 共识投票(去非确定性) + 卖出语义校准(≠做空) |

## 数据源与可靠性

- **加密**: OKX 永续 (行情/OI/费率) + HyperLiquid 官方 API (链上) — 均免费、沙箱可用
- **A股**: 东方财富 push2his (主) + 新浪财经 (兜底) — 直连 urllib, 不可带 Referer
- **美股**: TradingAgents-CN LLM 引擎 (SiliconFlow Qwen, 已锁模型防误调 DeepSeek-V3)
- **tradingbeats.xyz**: 聚合清算/Top10 大户可信; 24h 清算地址榜为占位假数据, 整体剔除
