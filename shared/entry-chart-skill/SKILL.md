# 交易入场 / 多空方案：必须出价格阶梯图

## 触发条件
当用户要求**任何标的**的以下任一类方案时，除文字分析外，**必须**用 Visualizer 生成一张价格阶梯 SVG 图：
- 入场方案 / 开仓计划 / 建仓建议 / 加仓计划
- 做多方案 / 多单 / 抄底
- 做空方案 / 空单 / 回调做空
- 多空方案 / 双向计划 / 突破追单

适用标的：加密永续、美股、A股、商品（黄金/原油等）、外汇——任何有价格的交易品种。「股种」泛指一切可交易标的。

## 图的内容规范
一张图同时呈现多空两套（或用户指定的方向），必须包含：
- **现价**：紫色虚线 + 标签
- **入场区**：做多入场（绿色实线/区）、做空入场（蓝色实线/区）
- **止损**：红色实线（多止损在入场下方、空止损在上方）
- **目标/止盈**：绿色虚线（多 TP）、做空目标区（绿色走廊）
- **关键支撑/阻力**：斐波那契位或前高前低，灰色虚线 + 标签
- **方向箭头**：做空向下蓝箭头、做多向上绿箭头
- **风险带**：止损外侧浅红填充，目标走廊浅绿/浅蓝填充

## 视觉规范（遵循 Visualizer 浅色主题）
- 背景透明/白，文本深色（#2C2C2A）
- 颜色语义：绿=#639922（多/目标）、红=#E24B4A（止损/风险）、蓝=#378ADD（空入场）、紫=#7F77DD（现价）、灰=#888780（斐波）
- 字号 ≥11px，无 emoji，无渐变/阴影
- 中文标签，简短（价格 + 角色，如「4325 多入场区」）
- viewBox 约 `0 0 680 520`

## 生成方式
1. 调 `read_me` 加载 `chart` 模块
2. 用 `show_widget` 输出 `<svg>`（纯静态阶梯图用 SVG 比 HTML 更稳）
3. SVG 内：`rect` 画走廊填充、`line` 画水平价位、`path marker` 画箭头、`text` 标价格与角色

## 参考模板（直接套用，仅替换价格/标签）
黄金 XAU 图结构：现价 4378；空入场 4440-4460 / 止损 4520 / 目标 4300；多入场 4325 / 止损 4260 / TP1 4408。配色与布局照此复制。

## 硬性约束
这是用户的长期偏好：**不要只给文字表就结束**。任何股种的入场/多空方案，图是必选项。若同时需要 PushPlus 推送，图应生成文件并附可下载链接（GitHub raw 或图床）。
